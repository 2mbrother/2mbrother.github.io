## 📁 폴더 구성

```
wedding-invitation/
├── index.html          ← 이 파일만 업로드하면 됩니다 (화환 배너/버튼/팝업 제거 완료)
├── README.md           ← 지금 보는 설명서
└── download_assets.sh  ← (선택) 이미지·JS·CSS를 내 서버로 완전히 옮기고 싶을 때
```

## ✅ 무엇을 지웠나

원본에서 아래 "화환 보내기" 관련 요소를 모두 제거했습니다.
- 하단에 떠다니던 화환 플로팅 배너 (`#floatingBanner`)
- "축하 화환 보내기" 팝업 (`.flower-float`)
- 계좌번호 아래 "화환 보내기" 버튼 (`.flowergiftsub`)
- 위 요소들을 움직이던 자바스크립트(`click_banner`, `open_flower_popup`, 플로팅 배너 스크롤 스크립트)

> 인사말의 "※화환은 정중히 사양합니다.※" 문구는 본문 내용이라 그대로 두었습니다.

## 🚀 가장 간단한 사용법

1. `index.html` 안의 `https://YOUR-DOMAIN.com/` **3곳**을 본인 도메인으로 바꿉니다.
   (카카오 공유·링크복사 시 연결될 주소입니다. 위치: `og:url` 메타, `.copy_url` 링크, `id="url"` 히든값)
2. `index.html`을 그대로 웹호스팅에 업로드합니다.

이 상태로도 사진·폰트·디자인·배경음악·지도는 바른손 CDN에서 바로 불러와 정상 표시됩니다.

## ⚠️ 자체 호스팅 시 꼭 알아둘 한계 3가지

1. **리소스 의존성** — CSS/JS/사진/배경음악/지도는 여전히 바른손 서버(`mcard.barunsoncard.com` 등)에서 로드됩니다. 예식 후 바른손이 자료를 내리면 깨질 수 있습니다. 완전히 독립시키려면 아래 `download_assets.sh`를 쓰세요.

2. **RSVP(참석의사) · 방명록** — 이 두 기능은 바른손 백엔드(`/m2/RsvpSave`, `/m2/GuestBookSave`)로 전송됩니다. 다른 도메인에서 호스팅하면 교차출처(CORS)·세션 문제로 **정상 저장이 안 될 가능성이 큽니다.** 이 기능이 꼭 필요하면 바른손 원본 청첩장을 함께 유지하거나, 해당 영역(`area23`, `attendIp_pop`, `area15`)을 삭제하세요.

3. **카카오 공유** — 코드의 카카오 앱키(`15a0...`)는 바른손 도메인에 등록돼 있어, 새 도메인에서는 카카오 공유가 거부될 수 있습니다. [카카오 디벨로퍼스](https://developers.kakao.com)에서 본인 앱키를 만들고 플랫폼에 새 도메인을 등록한 뒤 `Kakao.init('...')` 값을 교체하는 것을 권장합니다.

## 🧰 (선택) 완전 독립 호스팅 — download_assets.sh

저는 보안 정책상 이 환경에서 바른손 서버에 접속할 수 없어 자료를 직접 받아두지 못했습니다.
대신 **인터넷이 되는 본인 PC**에서 아래를 실행하면, 사진·JS·CSS를 내려받아 모든 경로가 상대경로인 `index_local.html`을 만들어 줍니다.

```bash
cd wedding-invitation
bash download_assets.sh
```

실행 후 생기는 `index_local.html` 과 `mcard/ res/ static/` 폴더를 통째로 업로드하면 바른손 서버 없이도 동작합니다.
(단, 일부 CSS 내부에서 참조하는 배경 이미지는 여전히 바른손을 가리킬 수 있어, 깨지는 이미지가 보이면 그 URL만 추가로 받으면 됩니다.)
